## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Romanbot4/Coursera-Assignment-Frontend-Developer-Capstone.git

   ```

2. Install dependencies

   ```bash
   cd Coursera-Assignment-Frontend-Developer-Capstone
   npm i

   ```

3. Start the development server

   ```bash
   npm run start
   ```
